# Agent & Developer Guidelines

- MCP server configuration lives in `src/lib/mcp/` (one tool per file).
- Application routes are defined in `src/routes/` using TanStack Start conventions.
- All client text and guidance must be trilingual, maintaining English, Hindi (`hi`), and Marathi (`mr`) translations in `src/lib/content.ts` and `src/lib/i18n.tsx`.
