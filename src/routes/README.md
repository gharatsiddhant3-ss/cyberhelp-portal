# CyberHelp — Application Routes

This directory contains the file-based routes for the CyberHelp portal, powered by TanStack Start.

| Route File | URL Path | Description |
|:---|:---|:---|
| `__root.tsx` | App Shell | Global header, trilingual provider, SEO tags, layout wrapper |
| `index.tsx` | `/` | Homepage with emergency quick-dial and feature overview |
| `report.tsx` | `/report` | Step-by-step reporting guide and emergency helplines (1930, 112) |
| `safety.tsx` | `/safety` | Safety tips and interactive Link & Domain Authenticity Inspector |
| `awareness.tsx` | `/awareness` | Cybercrime awareness guides (UPI fraud, phishing, fake jobs) |
| `breach-check.tsx` | `/breach-check` | Real-time email data breach search |
| `quiz.tsx` | `/quiz` | Interactive cyber-safety quiz with scoring and feedback |
| `survey.tsx` | `/survey` | Live field survey results and interactive charts |
| `contact.tsx` | `/contact` | Assistance request form with incident ticket ID generation |
| `mcp.ts` | `/mcp` | Model Context Protocol (MCP) server endpoint for AI assistants |
